# Project status

Snapshot date: 18 November 2026.

## Implemented

The offline CLI supports observation validation, causal temporal features, conditional proxy-crossing forecasts, diagnostic baselines, source-manifest integrity checks, and inspection and replay of the Pamplona temporal-density table. The parser checks the source's six-column tab-separated schema, increasing times, finite values, nonnegative densities, and trailing missing pairs. The viewer is self-contained HTML and makes no hazard classification.

The optional `assess_motion_quality` API gates motion cells using caller-supplied camera-stability and visibility evidence. The `project_motion_video` API conditionally maps eligible image-pattern displacement to a supplied reference plane using caller-supplied calibration. Missing evidence abstains. The software binds the supplied references and calibration to the motion result but does not independently verify them, infer visibility, establish pedestrian velocity, or measure motion accuracy. This API pair adds no CLI command or forecast integration. See the [offline research workflow](offline-research-workflow.md).

The source-inspection additions include `inspect-video`, which requires local `ffprobe` and `ffmpeg`, reports actual presentation timestamps, and performs video-only null decoding. A completed inspection separates timing abstention from command failure; optional `--max-gap-s` is caller-declared and is not a safety threshold. The Lyon reader is a Python API for one exact nine-column TopView ZIP member and its summary. It preserves source time, excludes `id_global`, and does not provide a calibrated motion-field pipeline.

`inspect-motion` requires local `ffprobe`, `ffmpeg`, and NumPy. It resizes grayscale frames to width 320 by default and samples at one-second intervals using actual decoder PTS. Its integer-pixel mean-SSD block matching is an image-space baseline, not a replication of Gu et al. or PIV. The resize dimensions are specified; physical scale and motion remain unknown. Camera motion and visibility are not assessed. Caller-nominated background cells are not independently verified. A unique SSD minimum does not measure confidence, accuracy, or visibility; a boundary match may be truncated by the search limit.

Baseline signals include current density, previous valid pressure proxy, and one-sided excess CUSUM against the causal past mean. Parameters are explicit research settings. They are not safety limits or calibrated warning thresholds. The CUSUM family is informed by Page (1954), not a calibrated reproduction.

Event matching and alarm-episode matching scope pooled data by recording identifier when present, otherwise event identifier, and by venue when supplied. Without identifiers, callers must partition inputs by recording. Episode matching expects selected alarm rows and does not automatically convert all forecasts to alarms.

The temporal-density source describes spatially averaged density in m^-2 against author-declared seconds relative to festival opening. It has 90,000 table rows and numeric counts of 80,025, 85,875, and 90,000 for 2022, 2023, and 2024. Trailing padding counts are 9,975, 4,125, and 0. It supplies no velocity, calibrated harm probability, or outcome labels. The original five selected CrowdDNA files total 4,697,499 bytes. The separately selected video is 51,275,828 bytes; the separate Lyon ZIP is 33,639,872 bytes. These are selected files, not complete record inventories. See the [video manifest](../sources/pamplona-video.json) and [Lyon manifest](../sources/lyon-topview.json). The full 1.22 GB CrowdDNA record was not fetched or audited.

## Evaluation

Only the global AR(1) fit uses 2022 training observations; local trend refits at each origin on the causal trailing 30 seconds, and persistence carries forward the latest observation. The 2023 check had 113 completed origins and the 2024 same-venue holdout had 118. Forecast errors use source-declared m^-2; source preprocessing and causal interpretation are unverified. The [result bundle](../results/pamplona-density-30s-2026-11-18/README.md) includes metrics, raw outputs, provenance, and the accepted figure. This one-series benchmark establishes no venue generalization, statistical significance, promotion, sensor accuracy, or warning performance.

## Rights and evidence limits

The source verifier checks local file size and checksums against a manifest. It does not fetch files or determine rights clearance. The selected video and Lyon archive manifests record CC BY 4.0 at record scope; integrity checks do not provide blanket rights clearance. A bounded controlled-archive source audit inspected 260,536-byte metadata and a 12,855,563-byte pressure ZIP, then read one matching member of 1,109,247 uncompressed bytes with 100 matrices. Response extraction was **NOT RUN**. Matrix units, pressure calibration, and pressure-to-camera mapping remain unverified. Archive terms permit research with attribution but do not grant redistribution. The Nature paper authors and CrowdDNA dataset-record authors are distinct. MIT covers original code only.
