# Crowd annotation source review

**Reviewed 2026-11-18.** This is a date-bounded review of public source descriptions and access. It is not an experiment protocol or result. No motion-accuracy or warning-effectiveness evaluation ran, and no source media or annotations are redistributed here.

The paper says labeling was ongoing and some agents were temporarily omitted; it does not specify interpolation rules. Table 2's "Briefly interact" means a short social exchange, not contact force. The paper separately lists a "Collision" field linked to colliding agent IDs, but no annotation export was accessed. | The author page was checked on 2026-11-18. Across these sources, a person's annotated box center is a sparse image-space reference for that person. It is not dense flow truth for the surrounding image patch. Interpolated boxes must not be counted as independent manual observations. None of the reviewed labels is an independently adjudicated crowd-crush outcome set. These sources do not establish calibrated force, physical compression, warning thresholds, or warning effectiveness.

## Synthetic optical-flow data

[TUB CrowdFlow](https://github.com/tsenst/CrowdFlow), described by Schröder, Senst, Bochinski, and Sikora in the [AVSS 2018 paper](https://elvera.nue.tu-berlin.de/files/1548Schr%C3%B6der2018.pdf), contains ten rendered sequences across five scenes, with static and moving-camera variants and author-provided flow fields and trajectories. The repository README describes the evaluation framework as MIT-licensed and separately restricts dataset use to academic purposes. These are CrowdFlow terms; this project's MIT code license does not grant rights to CrowdFlow data. Because its scenes are rendered, CrowdFlow may help check software behavior against synthetic flow labels; it cannot establish accuracy on real crowd video or replace real-data evidence.

## Access decision

CroHD has a current official release. The official supplement establishes that the annotations include manual keyframes and interpolated in-between frames. The public MOT release does not identify which rows were manually keyed, and its 1-based frame numbers do not reveal the keyframe phase. The 53,547,421-byte label archive and exact extracted members are recorded under ignored `.planning/crowd53/`. A 4.39 GB image archive was not downloaded. The member hashes below identify extracted files only; range-response hashes are not archive checksums.

The annotation member contains 21,456 nine-field rows, 85 tracks, and 429 frames. Frames 1 and 2 each have 40 rows. Their matching JPEG members are 1920 by 1080. The rows have no keyframe flag. A point-motion comparison at verified manual head centers is a valid sparse image-space question. It does not validate patch texture motion or dense optical flow. The earlier requirement for dense-flow truth for every image-motion comparison was too strict. The remaining genuine gate is identifying the exact manually keyed 1-based frame numbers and corresponding rows; the released files do not expose that phase. No comparison ran.

UCY's linked archive exceeds the bounded review size and its page gives no reuse terms; this does not establish whether selective access is possible elsewhere. SDD's official archive is about 69 GB, with no selective primary download route identified in the reviewed materials. The HUM-CARD author page currently has a work-in-progress placeholder and no link to annotation or source-video files. These are access findings from the sources reviewed on the date above, not claims that the datasets are unavailable everywhere.
